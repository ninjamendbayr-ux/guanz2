# ХААИС — Оюутны зоогийн газар (вэб сайт)

Оюутанд зориулсан хоолны цэс, дуртай хоол, сагс, очиж авах захиалгын түүх бүхий
олон хуудаст вэб сайт. Бүх хуудас нэг ижил `style.css` болон `script.js` файлыг ашиглана.

## Файлын бүтэц

```text
project/
├── index.html      — Нүүр хуудас
├── menu.html       — Хоолны цэс (хайлт, ангилал, эрэмбэ, дэлгэрэнгүй цонх)
├── favorites.html  — Дуртай хоол
├── cart.html       — Сагс
├── checkout.html   — Захиалга баталгаажуулах (очиж авах)
├── orders.html     — Захиалгын түүх
├── login.html      — Нэвтрэх / бүртгүүлэх
├── profile.html    — Миний бүртгэл
├── about.html      — Бидний тухай
├── contact.html    — Холбоо барих
├── style.css       — Цорын ганц CSS файл
├── script.js       — Цорын ганц JavaScript файл
└── assets/
    └── logo.png    — (заавал биш) албан ёсны ХААИС-ийн лого энд тавина
```

## Лого солих заавар

- Жинхэнэ ХААИС-ийн логоыг `assets/logo.png` гэдэг нэрээр энэ төслийн `assets/` дотор хуулж тавина.
- Сайт бүх хуудас дээр `assets/logo.png`-г автоматаар илрүүлж, нүүр болон footer дахь тэмдгийг шууд сольчихно.
- Лого байхгүй бол одоо байгаа SVG тэмдэглэгээ (текстэн) харагдана — хуурамч албан ёсны лого зохиогдоогүй.
- Харьцааг алдагдуулахгүйн тулд зураг `object-fit: contain`-аар харагдана.

## Хэрхэн ажиллаж байна (демо горим)

- Нэвтрэлт, сагс, захиалга бүгд **энэ вэб хөтчийн localStorage**-д хадгалагдана — бодит сервер байхгүй.
- Нууц үгийг энгийн текстээр биш, энгийн шифрлэсэн (`h1:`-ээр эхлэх) хэлбэрээр хадгална.
  Энэ нь демо зэрэглэлийн хамгаалалт бөгөөд бодит серверийн нууцлалыг орлохгүйг анхаарна.
- Захиалга, холбоо барихын мэдэгдэл зөвхөн уг хөтөчид хадгалагдана; илгээгдэхгүй.
- Хүргэлтийн систем байхгүй — бүх захиалга цайны газраас өөрөө очиж авах хэлбэртэй.

## Хялбар өөрчлөх тохиргоо (`script.js` дотор)

| Тогтмол | Утга | Тайлбар |
|---------|------|---------|
| `PICKUP_TIMES` | `["11:00", ..., "16:30"]` | Очиж авах боломжтой цагууд — ажиллах цагаа өөрчлөвөл зөвхөн энд засна |
| `PICKUP_SPOTS` | Төв байр / Оюутны төв / Дотуур байр | Очих байрнууд |
| `couponCodes` | `STUDENT10` 10%, `HA2026` 15% | Урамшуулын кодууд |
| `foods` | 24 хоолны мэдээлэл | Цэс, ангилал, үнэ, зураг |

Хуудас бүр `<link rel="stylesheet" href="style.css">` болон
`<script src="script.js" defer></script>`-аас бусад холбоос ашигладаггүй.

## Ажиллуулах

Хөтчөөр шууд `index.html` нээх боломжтой. localStorage хэрэглэдэг тул
http протоколоор үзэхийг зөвлөж байна (жишээ: `npx serve`, `python -m http.server` гэх мэт).
